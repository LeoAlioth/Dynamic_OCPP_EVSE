- [ ] **[BUG] Excess margin over-credits — watch-only potential issue** *(surfaced 2026-08-17 during the #41 latch rework; (b)'s grid-tied half fixed 2026-08-25 by the solar-only export term)* — (a) **curtailment over-credit**: battery full + export pinned at the limit, an engaged load's draw is folded back into export so the margin reads ~its draw too high; the latch verdict is right (the load eats curtailed energy) but the margin *is* the excess pool, so on a site with **two or more Excess loads** the second sees inflated surplus and can engage without real backing. (b) **off-grid discharge over-credit**: off-grid there is no export term for a discharge to be netted against — `_reconstruct_placement` returns export 0 and hands the managed draws back wholesale (the deliberate probe behaviour) — so a load whose draw exceeds the battery's charge allowance keeps the verdict engaged on its own draw while the pack drains, and falling SOC never releases it. Grid-tied this half is closed: `absorbed` now reduces to `production − household` whatever the battery is doing, so a load that pushes the pack into discharge no longer credits itself — except where per-phase clamping on an unbalanced site makes the site-level subtraction inexact. Act only on a real-site trigger: a second Excess load engaging without surplus, or an off-grid Excess load draining the battery. Fix directions if triggered: per-load pool attribution for (a); for (b) an off-grid signed battery term, which contradicts the documented absorbs-nothing/probe rule and its tests, so it needs its own design pass.
